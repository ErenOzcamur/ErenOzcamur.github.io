# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.
Do **not** open a public issue.

- Use GitHub's private vulnerability reporting (Security → Report a vulnerability), or
- Contact the maintainer directly.

Please include: affected version/commit, reproduction steps, and impact.
You will receive an acknowledgement as soon as possible.

## Supported Versions

The latest commit on the default branch receives security fixes.
